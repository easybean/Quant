# P2-05 目标 Linux 美股日线适配器黄金验收

执行日期：2026-09-09。NautilusTrader `1.221.0` 在目标 Linux 的隔离 Python
3.11 环境中完成了合成日线限价单的 P2-03 黄金验收；市价单仍保持阻断。

## 已验证的精确能力

`US_EQUITY` / `bar_frequency:1d` / `order_type:limit` 现登记为
`supported`，但仅限下面这个离线、合成的成交语义：现金账户，10 股买限价单，
一次性 L2 模拟流动性 `4@100`，随后撤销余下 6 股，固定一次性 `USD 1` 费用，
最终标记 `102`。

框架实际事件为 `OrderFilled(4@100, 1 USD)`、`OrderCanceled`，订单终态
`CANCELED`、已成交 4、剩余 6。框架账户/持仓再逐字段同
`p2-03-v1.equity-partial-fill-cancel-fee` 比对，均相符：`free_cash=599`、
`position=4`、`unrealized_pnl=8`、`fees=1`、`total_pnl=7`。

可复现命令（仅生成内存中三根 Bar，不读取真实数据或账户）：

```bash
/home/davidou/quant/runtime/nautilus-1.221/bin/python \
  /home/davidou/quant/p2-05-nautilus/run_p2_05_nautilus.py --order-kind limit
```

源码为 `scripts/run_p2_05_nautilus.py`，实际结果摘要保存在
`output/p2-05-nautilus-results.json`。

## 市价单的精确阻断差异

同一合成输入下，市价单确实产生了 `OrderFilled(4@100, 1 USD)`，且账户五项
数值也刚好相同；但 Nautilus 订单对象报告 `FILLED`、已成交 10、剩余 0，且没有
`OrderCanceled` 事件。这不能表达 P2-03 所需的“成交 4 后撤余单 6”生命周期，故
`order_type:market` 仍为 `unverified`，不得以账本数值巧合放行。

```bash
/home/davidou/quant/runtime/nautilus-1.221/bin/python \
  /home/davidou/quant/p2-05-nautilus/run_p2_05_nautilus.py --order-kind market
# exits 2 and emits the blocked difference
```

- `tests/test_market_capabilities.py` 断言只有该日线限价路径可用；请求市价单仍被门禁阻断。
- 未读取真实行情、raw/derived、凭证或账户；未连接券商/交易所；未部署或重启服务。

本验收不覆盖市价成交语义、滑点、公司行动、税费、保证金、日历/available-time 或真实回测数据接入。
