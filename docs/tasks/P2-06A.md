## 交付

- 将原本混合保存字段的 `universe_drafts` 拆为两个独立 SQLite 版本化存储：`InstrumentDraftStore` 管理一个证券、交易对或期货合约定义；`AssetPoolDraftStore` 管理研究资产池。
- 标的定义 API 为 `/api/v1/instrument-drafts`；每个版本保存一个经过 P2-01 合约模型校验的 `instrument`，支持列表、更新和历史读取。
- 研究资产池 API 为 `/api/v1/asset-pool-drafts`；写入只允许 `name`、`purpose` 和 `instruments`。每个成员严格是 `instrument_draft_id` 与 `instrument_version`，服务端核验对应不可变版本存在，拒绝空池、重复同一标的草稿、错误版本和任意额外字段。
- “市场与数据 → 资产与合约”改为只编辑单标的/合约定义；“研究实验室 → 数据集与资产池”改为独立页面，只选择已保存标的的当前版本、填写研究用途并查看资产池历史。两页的标题、边界说明、列表和空态均分离。
