# P6-00 风控规则中心与版本化策略

执行日期：2026-09-09。

## 交付

- 新增 `risk-policy-drafts.sqlite3`：全局风控规则草稿及不可变版本历史，记录名称、创建/更新时间、版本号和规范化的规则配置。
- 新增 API：`GET/POST /api/v1/risk-policy-drafts`、`GET /api/v1/risk-policy-drafts/{id}/history`、`PUT /api/v1/risk-policy-drafts/{id}`。
- 全局规则仅接受 `scope: global`，并保存单标的/单市场敞口、总毛杠杆、单日亏损、最大回撤、每分钟订单上限和停单开关。
- 服务端拒绝未知字段、非有限数、范围外阈值、非布尔停单开关、非整数频率，以及单标的敞口高于单市场敞口、单日亏损高于最大回撤等矛盾规则；错误以 HTTP 422 返回且不会落库。
- 新前端“风控中心 → 风控规则”提供创建、更新、历史查看，并明确区分：策略内选股/权重/调仓/止损等约束仍属于策略草稿，不属于全局风控规则。
