# P2-06 标的与资产池配置中心

执行日期：2026-09-09。

## 交付

- 新增 `quant_data.universe_drafts`：SQLite 版本化资产池配置草稿，支持创建、更新、列表和历史版本读取。每一版都保存用户提交的标的基础字段；没有行情读取器、账户连接器、运行器或任务提交入口。
- 新增 `/api/v1/universe-drafts`、`/api/v1/universe-drafts/{id}` 和历史接口，写入端只允许 `name` 与 `instruments`。服务端严格拒绝未知字段、非法日期/数值和不完整的嵌套规则。
- 复用 P2-01 `InstrumentDefinition` 校验稳定身份、ticker 生命周期、资产/产品组合、规则有效期与有限正数。补正交割合约分支：加密交割也必须有 `expiry`，不会再因分支顺序漏检。
- 新增“市场与数据 → 资产与合约”及“研究实验室 → 数据集与资产池”共用的配置页面。可填写美股、加密现货/永续/交割、国内/海外期货的市场、稳定身份、币种、合约乘数、到期日和最小交易规则，并查看草稿版本历史。
