# P1-09 TradingView 行情图表升级

执行日期：2026-09-09。

## 交付

- 将“市场与数据 → 行情浏览”的手写 SVG 替换为官方 `lightweight-charts@5.2.0`（TradingView Lightweight Charts）。继续调用既有内网只读 OHLCV API；没有 iframe、第三方请求或行情上传。
- 使用 v5 `createChart`、`CandlestickSeries` 与 `HistogramSeries` 绘制日线蜡烛和成交量，默认 `fitContent`，支持鼠标/触控平移与缩放。
- 十字光标同步显示日期、开高低收和成交量；`ResizeObserver` 适配容器尺寸，图表在数据、主题变化或组件卸载时断开观察器并销毁，避免残留 canvas/事件监听。
- 跟随站点深浅主题；保留官方 attribution logo，并附 TradingView Lightweight Charts 链接。原始/未复权、来源、质量和范围限制提示维持不变。
