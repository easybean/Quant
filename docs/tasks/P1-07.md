# P1-07 数据源接入中心

执行日期：2026-09-09。

## 交付

- 新增版本化 SQLite 数据源接入草稿：供应商、市场/产品、频率、覆盖声明、许可声明和服务器端凭证**引用名**。
- 新增网页入口“系统设置 → 数据源与交易连接”，支持创建、更新和查看历史版本。每一版固定显示为“已声明（未验证）”。
- 服务端严格接受供应商、市场/产品和频率白名单；未知供应商、不匹配组合、未知频率、路径形式的引用名和任何 `verified` 声明均返回 422。
- 凭证引用名只允许大写字母、数字和下划线；没有凭证值、文件路径、账户信息或供应商探测接口。存储、公开 API 与页面不含密钥字段，也没有日志记录。

## 边界

- 覆盖与许可均为用户的声明，不等于数据可用、账户可用或授权已验证。
- 本项不读取凭证/凭证文件，不调用外部供应商，不下载或扫描行情，不创建采集任务，也不改变任何既有数据快照。
