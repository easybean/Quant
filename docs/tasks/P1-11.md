# P1-11 免费美股历史 SIP 备源与研究数据收口

日期：2026-09-16。仅美股，仅免费数据；不购买套餐，不连接交易接口，不开放真实回测。

## 来源核实及真实探针

[Alpaca Market Data FAQ](https://docs.alpaca.markets/us/docs/market-data-faq) 明确区分 IEX 单交易所和 SIP 汇总行情：历史请求 end 至少早于当前 15 分钟可以不订阅查询 SIP。不能把实时 SIP、最新行情接口或 OTC 权限推断为免费可用；HTTP 200 也不证明当前账户没有付费订阅，更不证明完整许可、证券覆盖或研究资格。数据队列明确指定 SIP，不静默降级 IEX。

使用服务器现有数据凭证进行只读探针，无交易/购买请求、无凭证输出：

- AAPL 2026-09-01 至 15：HTTP 200，10 行。
- AACPW 2026-08-29 至 09-15：HTTP 200，11 行；现有 `_validate_normalized` 严格校验通过，volume 无缺失，可解决 Yahoo OHLC 冲突及 Nasdaq volume 为空造成的缺口。
- ABNG 同近期窗：HTTP 200，0 行；原因未知，不认定退市或无交易，不认定补齐。
- AAPL 2016-01-04 至 08：HTTP 200，5 行；只是该标的窄窗历史验证，不推广为全市场自 2016 完整覆盖。

初步诊断请求未固定 asof；正式工具和备源队列必须明确 `asof=-` 禁止供应商自动串接改名前后代码，记录纽约交易日及 UTC 请求边界。数据输出只按明确来源/namespace 使用，ticker 生命周期审查仍独立。

## 实施与验收要求

1. 可复现只读探针，固定日线/原始价/SIP、安全时间边界、有限超时，鉴权/限流立即停；不打印响应正文和凭证。
2. 独立 `alpaca-sip-recovery-v1` 失败窗队列，保留批次、哈希、实际日期、错误及来源；与 Yahoo、Nasdaq 原文件和锁隔离。每小时接手新失败，预算/熔断和同失败版本幂等，不使用试验样本缩减全量目标。
3. 未知 adj_close、分红、拆股保持未知；SIP OHLCV 不是完整公司行为或总回报证据。浏览层可有明确优先级合并尾段，正式研究不得静默拼接。
4. 严格自测、服务器隔离验收、真实 AACPW 落盘与 API 最新日期验证后记录部署；全市场覆盖不足不得勾选完成。
