## 交付

- 新增 `quant_data.jobs`：SQLite 状态库与产物目录固定在 `QUANT_WORKBENCH_STATE_DIR`，未配置时为 `QUANT_DATA_ROOT/workbench-state`，否则为项目 `data/workbench-state`。该目录与 raw/derived 分离。
- 状态机覆盖 `queued`、`running`、`succeeded`、`failed`、`cancelled`；失败包含稳定的代码/简短原因，取消在排队时立即生效、运行时记录请求并在安全点结束。
- `JobWorker` 使用最多 4 个受限 daemon worker（默认 1）；SQLite WAL + 原子 claim 避免同一任务被并发领取。重启时运行中任务恢复排队；若最终产物已原子发布，则只补记成功，不重复发布。
- 仅开放受控 `research / record_metadata`：持久化策略、参数、固定数据快照、代码版本和不可变产物索引。请求不接受任意代码、行情路径、网络、密钥或账户。
- P3-03 后续仅增加受控 `backtest / synthetic_daily_limit`：它必须携带固定合成版本和显式成交量，正式真实回测仍明确返回 422；P2-05 的合成美股日线限价验证不会被误作生产回测能力。
- API 增加任务/实验只读查询；网页仅以 5 秒 GET 轮询任务与实验状态，不提供提交按钮。任务概览、失败原因、空状态与实验追溯页已接入“回测任务”“任务与资源”“实验记录”。
