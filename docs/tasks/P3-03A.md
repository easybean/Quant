# P3-03A 真实研究资产池与日线限价再验收

日期：2026-09-16。阶段：快照验收协议与只读检查器；真实研究资产池尚未合格，正式回测仍阻断。

## 为什么不是先增加数据源

资产池草稿表达用户希望研究哪些标的；研究快照表达这些标的在固定时间范围内实际有哪些可用数据。保存草稿不等于数据齐备，数据源接入草稿也只代表声明，不代表已下载或已验证。

本阶段建立 `research-snapshot-v1` manifest 检查协议。不下载行情、不改原始数据、不创建线上标的/资产池、不修改研究任务或正式回测门禁。特别是现有 `QUANT_FACTOR_RESEARCH_SNAPSHOTS` 中的 `p3_03a_qualified=true` 不是完整数据验收证明；不得仅凭设置该标志放行真实研究。

## 固定快照合同

- 固定 `snapshot_id`、日历版本、时间范围和来源/namespace/许可证据；禁止可变 `latest/current/unknown` 标识。
- 每个成员有稳定 `instrument_id`、symbol、成员起止日期和身份依据；不能把当前上市清单伪装成历史全市场资产池。
- 日线价格口径为原始成交价；行情、身份、历史成员、日历文件均需登记 SHA-256。
- 可用时间声明必须是 `explicit_available_time` 并有依据；公司行为与退市覆盖必须有证据，未知即阻断，`not_applicable` 必须给出狭窄范围的理由。
- 文件只允许 manifest 所在目录内的相对路径，校验实际文件哈希，拒绝路径越界及越界符号链接。

检查结果的 `ready_for_review` 只表示合同与文件完整性足够进入下一步审查；`qualified` 始终为 false。检查器不能证明供应商声明真实、行级 PIT 正确、历史成员完整、公司行为无遗漏或研究有效，也不能打开回测。

## 接下来的数据补齐顺序

1. 盘点现有行情与证券清单，先选择明确、有限的研究范围，记录缺口；禁止以今天仍存续的股票组成“历史全市场”。
2. 优先补稳定身份/历史成员、交易日历、完整公司行为和退市结算；缺口必须隔离或保留阻断，不推断最终兑付。
3. 针对缺口接入授权数据源，登记许可、覆盖、修订、可用时点与限速，发布独立不可变快照；不得把供应商空响应当作无事件。
4. 行级数据审查与黄金样例通过后，再建立单独的研究资格证据和受控注册；真实日线限价成交/成本路径仍需独立再验收。

现有 yfinance/Nasdaq/Alpaca 下载能力及代表性 Alpaca 公司行为样本均须按实际范围使用，不能被本协议自动升级为完整历史覆盖。新增付费源或外部账户连接另行确认。
