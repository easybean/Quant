## 交付范围

- “总览 → 我的工作台”改为并行读取三个既有只读端点：数据目录、因子目录和健康端点。
- 仅展示响应中的原始日线文件数、因子数、分类数、质量发现、市场/频率、覆盖区间、快照时间和 API 健康状态。

## 数据来源与边界

| 区域 | 来源 | 边界 |
| --- | --- | --- |
| 数据资产、质量、覆盖 | `GET /api/v1/data-catalogue` | 仅四个预生成 JSON 快照；请求不扫描 Parquet、不下载数据。 |
| 因子定义 | `GET /api/v1/factors` | 运行时因子注册表；不代表因子预测能力已验证。 |
| 只读 API | `GET /api/v1/health` | 仅说明 API 响应正常，不代表回测、订单或市场连接状态。 |

页面同时展示数据和因子各自的生成时间，以及数据覆盖区间。任何一个必需响应失败时，整页保留加载失败说明和“重新读取快照”，不会回退到演示数据。
