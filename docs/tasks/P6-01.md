# P6-01 模拟账户与订单台账基础

执行日期：2026-09-09。

## 交付

- 新增 `quant_data.paper_ledger` 与本地 SQLite `paper-ledger.sqlite3`。模拟账户固定为 `paper` 类型，创建时明确保存名称、基础币种、初始现金和保证金模式（现金/全仓/逐仓）。
- 新增不可变事件表，定义 `order`、`fill`、`fee`、`audit` 四类记录；事件带稳定去重键、规范化 JSON、现金/仓位变动和记录时间。数据库触发器拒绝更新和删除；相同去重键的相同输入幂等返回，冲突输入拒绝。
- 新增 API：`GET/POST /api/v1/paper-accounts` 与 `GET /api/v1/paper-accounts/{id}/ledger`。HTTP 只允许创建账户和读取台账，未提供订单、成交、费用或审计事件的写入接口。
- 新前端“组合与账户 → 模拟账户”（以及订单与成交、资金流水的同一只读入口）可创建账户、读取事件与账本现金勾稽；空状态明确说明未连接行情/券商，无法自行产生订单或成交。
- 勾稽只报告 `初始现金 + 已记录现金变动 = 账本现金` 与净记录仓位；明确不计算 PnL、盯市、保证金或券商余额，避免伪造绩效。

## 边界

- 不读取行情、不启动 Docker、不部署；没有撮合器、回测、本地实时模拟、外部模拟账户或实盘路径。
- 页面/API 不生成演示成交，且写入端不会暴露给浏览器。未来仅在 P3-03/P5 的产品规则通过后，才可由受控流程把已验证订单和成交写入台账。
- 初始账户配置不修改；本任务没有账户编辑、资金出入金、仓位估值、风险计算或自动恢复能力，后续分别由 P6-02/P6-03 覆盖。
