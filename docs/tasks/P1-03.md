# P1-03 公司行为、身份和退市结果：免费来源可行性审计

执行日期：2026-09-08。访问日期：2026-09-08。

## 范围与结论

本项是来源与可行性审计，不是补数任务。未下载全量数据、未使用/读取任何密钥、未修改 raw 或 derived；也没有把缺失交易日归为停牌。

结论是：现有日线能够保存 **未复权价格与成交量**，但不能支持含现金分红、拆股持仓调整、合并/退市结算的总回报回测。免费且可审计的补数可以先做到“少量事件的来源快照与人工核验”；要得到 2016--至今、全美股、完整退市最终兑付的机器可用基线，当前没有已验证的免费可靠来源。Alpaca Corporate Actions 是最值得先做授权探针的候选，不能在未验证该账户历史保留与许可前视为已覆盖。

## P1-04 可复现实施清单（不在本任务执行）

1. **授权探针而非全量下载**：由专用运行命令读取部署环境中的 Alpaca 认证，但日志只输出 HTTP 状态、记录数、最早/最晚 `process_date`、分页是否完整和字段名；绝不打印 key、secret、URL 中的凭证或响应的个人账户信息。针对 AAPL（分红/拆股）、TSLA（拆股）、TWTR/ATVI（收购）各取窄日期窗。若任一样本无权限、无 2016 起历史、无必要字段或许可不合用，即不能选为主来源。
2. **新建独立原始事件层**：只写 `data/reference/corporate-actions/<source>/<snapshot-id>/`，附 manifest（请求条件、retrieved_at、条款 URL、schema hash、分页 token hash/计数），不触碰 `bars/daily` 或 `derived/structural-v1`。
3. **最小事件 schema**：`source_event_id, source, retrieved_at, data_quality, action_type, process/announcement/ex/record/payable/effective_date, symbol_as_reported, instrument_id, cik, cusip, isin, old_symbol, new_symbol, ratio_numerator, ratio_denominator, cash_amount, currency, new_instrument_id, source_url, confidence, notes`。日期字段可空但不得以 `process_date` 代替 ex/payable date。
4. **身份与退市 schema**：`instrument_id, venue, venue_symbol, cik, cusip, isin, listing_date, delisting_date, ticker_effective_from/to, identity_confidence, provenance`；另建 `delisting_resolution`，至少有 `reason, final_cash_per_share, final_security_id, share_ratio, settlement_date, evidence_url, confidence`。未知值为 null/unknown，不制造零回报。
5. **三类黄金样例**：AAPL（现金股息 + 4-for-1）、TSLA（3-for-1）、TWTR（现金并购 $54.20）；ATVI 作为第二个现金并购；每个样本与一手来源、事件层、持仓/现金人工账本三方对照。GE 在取得其一手比例资料后用于 reverse split。
6. **日历与状态**：新增 venue calendar snapshot，保存下载/访问日、覆盖区间、时区和 early-close；任何文件内未出现的日期默认 `unknown_missing_reason`。单证券停牌/恢复须有带日期、venue、instrument identity 的权威状态记录才允许标注。
7. **资产池门槛**：在 P1-04 完成前，研究只能使用 `price_only_unadjusted` 标签；需要总回报或退市收益的策略不得运行。完成后仅放行 `actions_complete_for_scope=true` 且 `delisting_return_known_or_not_in_window=true` 的明确范围。
