# P1-04：公司行动窄窗补数与版本化 Curated 层

日期：2026-09-08。范围严格限于 P1-03 定义的授权探针与代表性事件；没有执行全市场下载、付费采购、复权重写或退市回报推断。

## 结论与研究边界

Alpaca Corporate Actions 端点在本账户下可读：5 个窄窗口均返回 HTTP 200；2016 年 AAPL 窗口返回了事件，AAPL 2020 窗口以 `limit=1` 取得并成功续用了分页令牌。返回结构包含 `corporate_actions` 和 `next_page_token`，且样本涵盖 `cash_dividends`、`forward_splits`、`cash_mergers` 三类所需字段。

已建立一个可复现的 **代表性事件验证资产**，不是完整的总回报研究资产池。允许的用途仅为：公司行动 schema/mapping、持仓和现金账本的事件级黄金样例。任何常规回测、因子检验或“十年全市场总回报”仍不得因该快照而放行；退市最终回报仍为 `null/unknown`，不能当成零。

## 新版本与不可变性

服务器创建的目录（均为新建、拒绝覆盖）：

- 原始 API 页面：`/home/davidou/quant/data/reference/corporate-actions/alpaca/20260908-narrow-v1/`
- Curated 映射：`/home/davidou/quant/data/curated/reference/corporate-actions/alpaca/20260908-narrow-v1/`

原始层含 5 个 JSON 页面与 `manifest.json`；manifest 记录查询窗口、获取时间、HTTP 状态、顶层 schema、分页令牌 **hash** 和文件 SHA-256，绝不写 API key、secret、账户信息或令牌原文。Curated 层含：

- `events.jsonl`：26 列最小事件 schema；未知的 `instrument_id`、CIK/ISIN、证券映射及退市结算均保持 `null`。
- `schema.json`：字段与 schema hash。
- `verification-report.json`：样本核验和总回报适用性结论。

新增实现：[corporate_actions.py](../../src/quant_data/corporate_actions.py)、[capture_corporate_actions.py](../../scripts/capture_corporate_actions.py)、[test_corporate_actions.py](../../tests/test_corporate_actions.py)。脚本固定为 5 个窗口：AAPL 2016、AAPL 2020、TSLA 2022、TWTR 2022、ATVI 2023；不接受全量范围参数。

## 遗留与后续

- 当前快照不提供完整 AAPL/TSLA 股息历史，更不提供全市场 action 覆盖。
- ticker 不是稳定证券身份；`instrument_id` 与 lifecycle 映射仍待 P2-01/P2-02 规则模型。
- TWTR、ATVI 以外的退市最终回报未知；即使这两个并购事件通过，也不可以推断其他退市结果。
- P1-05 只能将本版本展示为“代表性验证快照 / 非全市场覆盖”，不得在 UI 宣称数据完整。
