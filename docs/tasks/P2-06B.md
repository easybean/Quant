# P2-06B 自动证券档案与资产池引用对接

状态：2026-09-18 用户配置对接已实现、部署、端到端验收；完整历史身份/行情归属/交易规则及研究资格仍待核验，整项不提前勾选。来源目录自动建档见UX-03，旧InstrumentDraftStore引用历史保留兼容。

目标：用户搜索/选择证券，系统负责身份、行情归属与交易规则，不要求用户填写技术档案。

门禁：内部来源记录ID不是已核验永久证券ID；不得为满足旧必填字段虚构历史生效日、统一tick/lot或日历。结合生命周期、来源证据、公司行为和代码复用校验行情归属；来源冲突、日期缺失、身份不确定保留待核验。免费源与许可符合要求后才形成固定版本映射。

引用接口须兼容现有草稿和策略版本锁定，发布新引用/schema，不原地迁移旧研究工件。自动研究池与历史指数成员是不同问题，不用今日成分回填历史。

验收：无需手填创建证券档案；自动证券引用与旧资产池/策略版本可追溯；重复导入、改名/代码复用/退市、缺规则fail-closed覆盖；资料可浏览不自动获得研究资格。真实回测门禁继续保留。

## 2026-09-18 配置链路交付

- 自动成员请求仅接受 `member_type=security_catalogue_v1`、`catalog_id`、`source_checksum`。服务端从固定导入manifest与record snapshot解析，持久化来源快照，不信任浏览器传入的证券资料或研究资格。
- 目录增加current checksum关联及不可变快照表；使用已核实的原来源 `security_master.consolidated.parquet` 字节一致重导补建旧目录快照。第一次误用采集主表时缺少sources/provenance被严格拒绝，未放松校验；纠正路径后24,516条成功关联。
- 当前或历史快照已隔离的证券均禁止新引用；伪造快照、未知checksum、重复catalog_id拒绝。退市可选为历史研究名单，但身份、最终回报、规则和日历未知时不获得研究资格。
- 股票池网页支持代码/名称搜索、跨搜索保留已选名单、移除、新建/编辑、必填标记与字段错误、加载/空/失败、保存成功与历史。旧成员可保留，不原地迁移工件。
- 策略引用固定股票池 ID/version，不随股票池或目录更新改变。没有修改factor_jobs/backtest门禁。
- “数据覆盖与质量”增加只读同步摘要；待开发菜单默认收起，可以显示全部后续功能。详见 [同步修复](SYNC-20260918.md)。
