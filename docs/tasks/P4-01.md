# P4-01 因子公式与可用性校准

执行日期：2026-09-09。公式版本：`p4-01-v1`。

## 范围与边界

- 只用合成 OHLCV 黄金输入和已安装依赖的输出校准 `factor_lab`/目录；没有读取真实原始行情，也没有计算、改写或生成 raw/derived 数据。
- 未部署 API 或 UI。目录数和 IMXD 状态发生变化，须在后续统一发布前按 P0-01 的真实浏览器流程复验，不能把本地专项通过写成已发布。
- P4-02 之前没有持久化的因子实验产物；因此不存在要迁移的旧实验结果。`p4-01-v1` 已写入核心注册表，后续实验记录必须保存该公式版本，不能把新公式结果标作旧口径。

## 依赖和黄金校准

- 依赖契约：`ta 0.11.x`；实际对照环境为服务器既有 `ta==0.11.0`。本机没有把依赖装进项目 venv，而是经清华 PyPI 镜像临时安装到 `/private/tmp/quant-p4-ta` 后运行测试。
- Qlib 参考：`Alpha158DL.get_feature_config`，2026-09-09 读取 Qlib 主线源。该参考定义 `IMAX=IdxMax(high,d)/d`、`IMIN=IdxMin(low,d)/d`、`IMXD=(IdxMax(high,d)-IdxMin(low,d))/d`。
- 合成五行黄金样本使 high 的最低点与 low 的最低点不同；它断言 `IMAX5=4/5`、`IMIN5=0`、`IMXD5=4/5`，从而覆盖此前错误的 high/high 与 `d-1` 缩放。
- `ta.add_all_ta_features(..., fillna=False)` 实际给出 86 个输出。新增此前遗漏的可研究输出：`trend_adx`、`trend_adx_pos`、`trend_adx_neg`、`trend_cci`。

## 可用性和兼容性结论

| 项目 | 结论 |
| --- | --- |
| `ta_trend_psar` | 保留旧稳定 ID 但不可运行：ta 0.11 只输出 `trend_psar_up/down` 及切换列，没有单一 PSAR 总列。 |
| `ta_trend_ichimoku_*_visual` | 保留旧稳定 ID 但不可运行：实际名称为 `trend_visual_ichimoku_a/b`，它们是视觉前移序列，禁止作为研究/回测输入。 |
| VWAP | Alpha158 的五个 VWAP ID 继续不可运行。结构派生层没有 `vwap`，绝不以典型价或其他代理价格填充。 |
| IMXD | 已按 Qlib 参考修正并转为可计算；IMAX/IMIN 同步采用 Qlib 的 `/d` 缩放。 |
| Alpha158 | 仍是本地兼容词汇，不是严格官方特征集：本地 158 项为 9 K-bar + 25 价格滞后（含 CLOSE）+ 5 成交量滞后 + 119 滚动项；Qlib 常见默认组合为 9 + 4 + 145。详情页继续明确本地公式和差异。 |
| 重复关系 | 注册表的 `redundancy_group` 保持为面向研究的近似重复组；新增 ADX/+DI/-DI 同属趋势指标组，CCI 属震荡/强弱组。它们不是可替代或收益等价的声明。 |

旧 PSAR/Ichimoku ID 的不可运行状态与 API 的 `runnable=false` 保持一致；视觉列虽为上游输出，也不新增为可选研究因子。`CLOSE0`、`VOLUME0` 继续因常量而不可单因子检验。
