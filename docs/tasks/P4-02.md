# P4-02：异步因子检验 API 与页面

执行日期：2026-09-09。实现了受限的单因子研究任务，但**没有**放开真实收益计算：生产环境未登记 P3-03A 合格资产池时，页面和 API 都保持阻断。

## 交付

- `research/factor_evaluation` 复用 P3-01 SQLite worker、幂等键、取消/重启恢复和原子产物发布；只接受固定模板 `single_factor_evaluation-v1`。
- 快照必须由服务器环境变量 `QUANT_FACTOR_RESEARCH_SNAPSHOTS` 登记（不可由浏览器提交路径），且条目明确 `p3_03a_qualified: true`。登记项同时固定 `derived_root` 与 `factor_formula_version`；公共接口仅返回版本和资格，绝不返回目录路径。
- 未登记快照、P1-04 代表性事件快照、未通过 P3-03A 的资产池都会在提交前以 422 阻断。因子不可运行、常量/缺列导致无有效截面、样本/分组不足均得到明确失败状态，不会显示伪结果。
- 成功任务保存 `factor-report.json`，追溯因子、参数、数据快照、公式/代码版本、覆盖统计、IC（RankIC）、等权分组远期收益和单向换手。结果明确为研究统计；不含复权、公司行动、费用、滑点或退市最终回报，绝不是可执行策略收益。
- 新增 `/api/v1/factor-research/availability`、`/api/v1/jobs/{id}/result`，并将因子研究页改为：目录因子选择、固定快照门禁、异步状态、结果/阻断/失败态。没有加入演示数据。
