# P3-02B 可视化策略构建器

执行日期：2026-09-16。状态：已实现并部署，尚缺代表性浏览器点击验收。

## 范围与边界

- 版本化保存策略名称、固定资产池草稿 ID/版本、当前可运行因子规则、规则组合、调仓周期、目标仓位及策略内持仓约束。
- 服务端严格校验字段白名单、已保存资产池版本、当前可运行因子、有限数值、重复规则和版本历史。
- 该定义没有运行入口：不执行因子、不读取行情、不回测、不生成收益、信号或订单。
- 策略内约束不替代全局风控；账户敞口、杠杆、损失和停单继续由独立的全局风控规则管理。

## 本地真实证据

- 部署前核验：API 对可视化策略路由返回 404，已部署 API 缺少对应模块/路由；线上静态 UI 已包含入口，形成“页面存在、保存接口缺失”的前后端不一致。
- 本地存储为 `visual-strategy-drafts.sqlite3`，创建和更新均追加不可变版本；引用只保存资产池 ID/版本，不复制成员或因子公式。
- UI 显示加载、空、读取失败重试、保存失败、版本历史；编辑旧资产池版本时保留旧引用并可明确切换至当前版本；历史中已变为不可运行的因子仍显示为保留引用，但服务端拒绝把它保存为新版本。
