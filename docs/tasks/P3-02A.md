# P3-02A 策略工作台与版本化草稿

执行日期：2026-09-09。

## 交付

- 新增固定策略模板 API：`GET /api/v1/strategy-templates` 仅返回 P3-02 已定义的买入持有和双均线模板、固定版本、显示用参数说明。
- 新增 SQLite 草稿存储 `strategy-drafts.sqlite3`（与 P3-01 状态目录同级）：创建、更新均保存不可变版本历史；当前草稿记录名称、固定模板/版本、经服务端校验的参数、创建/更新时间与版本号。
- API 提供草稿列表、创建、更新和历史读取。未知模板、缺少字段、窗口关系错误和非法权重均返回 422，不会落库。
- 新前端“策略中心”的三个入口共用策略工作台：浏览固定模板、仅编辑模板允许的参数、保存草稿/新版本、查看草稿历史。页面明确标为“草稿 · 不可执行”。
