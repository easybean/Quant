三份下载 manifest 的最新状态如下：

| 任务集 | 请求代码数 | 成功 | 最新失败 | 备注 |
| --- | ---: | ---: | ---: | --- |

## 行情字段、来源与复权（分区抽样）

每个分区抽样的 raw Parquet 都有 `date, symbol, open, high, low, close, adj_close, volume, dividends, stock_splits, source, adjustment_status`，因此可确认 OHLCV 字段存在。Alpaca 样本额外有 `feed`；基准样本额外有 `actions_status, assetclass, collected_at`。

- legacy Nasdaq 下载 manifest 标为 `source=nasdaq_web_unadjusted`、`adjustment_status=unadjusted`、`actions_status=not_available`。
- Alpaca（IEX）下载 manifest 标为 `source=alpaca_stock_historical_v2`、`adjustment_status=raw`、`actions_status=not_available`。
- `structural-v1` 只做结构清洗，明确**未计算复权价、未处理退市收益或合并/OTC 结果**；它保留/标记 `adjustment_status`，不应被当作可直接用于含公司行为收益回测的完整数据。

以上字段是分区抽样与 manifest 的结论，不是对每个文件逐一重新读 schema 的声明。

## 已有质量审计与缺口

结构清洗审计显示 10,640 个非基准文件都可读且满足必需 schema，但记录了：

- `missing_provenance_metadata`：6,931 个受影响文件；
- `missing_required_value`：2,830 个文件、418,615 个字段值；
- `ohlc_relation_invalid`：121 个文件、211 行。

下载失败仍是主要覆盖缺口：default 6,211、retry 57、delisted 3,248 个代码的最新尝试失败。单文件的可用日期也不等于请求的 2016-01-01 起点；全量索引实际最早只到 2016-08-29，且不同分区最早日不同。

因此，这份数据**不能宣称覆盖全部美股、全部当前普通股，或最近十年完整的退市证券历史**。尤其不能将「delisted 任务集成功 3,444 个 ticker」等同于已经拥有完整的退市价格、最终兑付及公司行为数据。

## 可复现只读核验

以下命令均只读；聚合使用现有 manifest/审计表，不扫描全部行情内容：

```bash
ssh davidou@192.168.1.132 'du -sh /home/davidou/quant/data /home/davidou/quant/data/bars/daily /home/davidou/quant/data/derived/structural-v1; df -h /home/davidou/quant/data'
ssh davidou@192.168.1.132 '/home/davidou/quant/venv/bin/python -c "import pandas as p; x=p.read_parquet(\"/home/davidou/quant/data/audit/structural-v1/coverage.parquet\"); print(len(x), x.symbol_key.nunique(), x.input_rows.sum(), x.first_date.min(), x.last_date.max())"'
```

本次实际读取的索引文件包括 `audit/structural-v1/{quality-summary.json,coverage.parquet,anomalies.jsonl}`、三份 `manifests/**/download.jsonl`、`metadata/security_master*.parquet` 和各分区的一份 Parquet schema。没有部署、服务重启或数据写入；无回滚动作。
