# P1-08 现有美股日线行情浏览

执行日期：2026-09-09。

## 交付范围

- 新增“市场与数据 → 行情浏览”，可按证券代码搜索既有美股日线的**独立来源序列**，选择不超过 366 个日历日的区间，绘制 OHLC 图并展示成交量字段、来源、覆盖范围和质量边界。
- 新增只读 API：`GET /api/v1/market-data/us-daily/search` 与 `GET /api/v1/market-data/us-daily/bars`。搜索限定 1–32 字符且最多 20 项；K 线查询必须使用固定索引中的 `series_id`，区间最多 366 天、响应最多 300 行。
- 新增离线命令 `quant-data daily-browser-index`。它只读取既有 `audit/structural-v1/coverage.parquet`（以及存在时的 `audit/quality-v1/findings.parquet`），输出新文件 `catalogue/us-daily-browser-v1.json`；不读取任意行情文件、不改写 raw/derived。HTTP 请求仅读取该固定 JSON，再读其中选择的一个 raw Parquet。

服务器生成索引（不部署、不下载）：

```bash
PYTHONPATH=src /home/davidou/quant/venv/bin/python -m quant_data.cli daily-browser-index \
  --audit-root /home/davidou/quant/data/audit/structural-v1 \
  --output /home/davidou/quant/data/catalogue/us-daily-browser-v1.json
```

## 安全与数据边界

- `raw_relative_path` 只在离线索引内做严格格式校验；浏览器/API 不接收路径，响应也不暴露路径。服务端再次校验选中路径仍位于固定 `bars/daily` 根目录。
- 同一 ticker 的 provider/namespace 文件以不同序列显示，绝不自动拼接。无数据仅表示这个来源序列在请求区间无 bar，不能推为停牌。
- 图表固定标为原始/未复权价格；公司行为、退市最终回报和全市场完整覆盖均未处理，页面不含回测或下载入口。
