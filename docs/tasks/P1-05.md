# P1-05 数据目录页面接入

执行日期：2026-09-08。

## 交付范围

- 新增“市场与数据 → 数据目录”页面，显示日线覆盖、来源分区、数据/规则版本、质量发现筛选和公司行动快照边界。
- 新增只读 `GET /api/v1/data-catalogue`。请求只打开四个**固定名称**的 JSON 快照：盘点、质量、结构清洗、公司行动验证；不会遍历目录、读取 Parquet、下载数据或接受客户端路径。
- API 对盘点快照使用字段白名单，响应不包含服务器绝对路径、凭证或快照内部字段。
- 服务器新增 `catalogue/inventory-v1.json`，依据 P1-01 已核验的索引统计生成；它是新建摘要文件，不改写 `bars/daily` 或 `derived/structural-v1`。

## 目录页面边界

- 页面有加载、服务失败重试和空数据提示；没有演示数据或独立下载入口。
- “质量与缺口”是快照发现数的前端筛选，不会在浏览器触发服务器重算。
- 公司行动区域固定标为“代表性事件验证，非全市场公司行动覆盖”；展示 6 条样本事件与 5/5 黄金样本，退市最终兑付保持 `unknown`，不宣称全市场总回报可用。
