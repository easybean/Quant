# 第一阶段需求确认清单

以下答案会直接决定是否采用 LEAN、数据存储和模拟撮合的复杂度。

## 市场与交易

- [ ] 市场：A 股 / 港股 / 美股 / 期货 / 期权 / 外汇 / 加密资产
- [ ] 品种范围与预计证券数量
- [ ] 策略频率：日频 / 分钟 / Tick / 逐笔委托成交
- [ ] 模拟精度：收盘价成交 / Bar 内撮合 / 盘口撮合 / 队列位置近似
- [ ] 单策略或多策略；策略间资金、持仓是否隔离

## 数据

- [ ] 实时行情供应商、协议和授权范围
- [ ] 历史数据来源、年限、复权口径和更新 SLA
- [ ] 是否有 Level-2、逐笔、基本面和另类数据
- [ ] 是否允许把数据落到内网数据库，保存期限与并发限制

## 平台与运维

- [ ] 服务器操作系统、CPU/内存/磁盘及是否可用 Docker/Kubernetes
- [ ] 内网是否完全离线；镜像和 Python/.NET 包如何导入
- [ ] 并发策略数、用户数、可接受延迟与可用性目标
- [ ] 认证方式、角色权限、密钥托管和审计保留期
- [ ] 告警渠道、备份、灾备与故障恢复目标

## 第一版建议边界

只选一个市场、一种行情源、一类资产和一个简单策略；先做单账户模拟盘，不接真实下单通道。管理面只提供策略启停、资金持仓、订单成交、PnL、日志和告警。
