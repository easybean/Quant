# 页面名称与使用指南

2026-09-17：按当前已实现能力整理。页面显示“已开放”“受限”或“待开发”；已开放也不代表行情完整、策略有效或可实盘交易。导航名称、页面标题与面包屑使用同一口径，原有路由 ID 保持不变。

普通使用顺序：行情浏览 → 数据覆盖与质量 → 研究股票池 → 我的策略 → 新建回测 → 研究记录。当前这条链路尚未完全开放：股票池仍使用旧档案引用，真实正式回测与自动模拟执行仍被门禁阻断。

证券档案是系统维护的证券资料；行情是价格记录；股票池是选股的候选名单，不是资金池；指标（因子）是衡量股票的方式；策略是选股和仓位规则；账户与资金用于模拟账务。保存名单或策略不等于运行交易。
